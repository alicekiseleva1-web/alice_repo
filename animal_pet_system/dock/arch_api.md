# Проектирование API

## Тип API

REST API

## Базовый путь

```
/api/
```

API предназначен для взаимодействия клиентского приложения с серверной частью системы поиска пропавших домашних животных и помощи приютам.

Основные задачи API:

- регистрация и авторизация пользователей;
- управление профилем пользователя;
- работа с животными;
- создание и обработка объявлений;
- поиск животных;
- обмен сообщениями;
- работа с приютами;
- обработка заявок помощи.

---

```
/api/

├── auth

```

# Модуль `auth`

Модуль отвечает за регистрацию, авторизацию и управление токенами доступа.

Реализуется отдельным сервисом авторизации.

Основные функции:

- создание учетной записи;
- проверка логина и пароля;
- выдача токенов доступа;
- обновление токенов;
- проверка токена пользователя.

---

## Регистрация пользователя

### POST

```
/api/auth/register
```

Назначение:

Создание новой учетной записи пользователя.

Входные данные:

```json
{
    "first_name": "Иван",
    "last_name": "Петров",
    "email": "user@mail.ru",
    "password": "password"
}
```

---

## Авторизация пользователя

### POST

```
/api/auth/login
```

Назначение:

Проверка учетных данных пользователя.

Ответ:

```json
{
    "access_token": "token",
    "refresh_token": "token"
}
```

---

## Проверка токена

### POST

```
/api/auth/verify
```

Назначение:

Проверка валидности токена.

Ответ:

```json
{
    "user_id": 15,
    "role": "FRIEND"
}
```

---

## Обновление токена

### POST

```
/api/auth/refresh
```

Назначение:

Получение нового access-токена.

# Модуль `animals`

Работа с информацией о животных.

---

## Создание животного

### POST

```
/api/animals
```

Назначение:

Добавление информации о животном.

---

## Получение информации о животном

### GET

```
/api/animals/{animal_id}
```

Возвращает:

- основные данные животного;
- статус;
- фотографии;
- связанные объявления.

---

## Изменение информации о животном

### PUT

```
/api/animals/{animal_id}
```

---

## Добавление фотографии животного

### POST

```
/api/animals/{animal_id}/photos
```

---

## Получение фотографий животного

### GET

```
/api/animals/{animal_id}/photos
```

---

## Поиск животных

### GET

```
/api/animals/search
```

Параметры поиска:

- город;
- порода;
- окрас;
- пол;
- статус.

Пример:

```
/api/animals/search?city_id=1&status=LOST
```

# Модуль `reports`

Работа с объявлениями о животных.

---

### POST

```
/api/reports
```

Назначение:

Создание объявления:

/api/reports

### GET

```
/api/reports/{report_id}
```

---

## Изменение объявления

### PUT

```
/api/reports/{report_id}

---

```

- животное найдено;
- животное пристроено;
- проблема решена.
