# Проектирование базы данных

## БД: PostgreSQL

## Назначение

База данных предназначена для информационной системы поиска пропавших домашних животных и взаимодействия пользователей с приютами.

База данных обеспечивает хранение:

- информации о пользователях;
- информации о животных;
- данных о приютах;
- объявлений о пропаже и нахождении животных;
- сообщений пользователей;
- заявок помощи приютам;
- справочной информации.

Справочник статусов животных.

## Структура таблицы:

| Поле | Описание |
|---|---|

## Значения:
