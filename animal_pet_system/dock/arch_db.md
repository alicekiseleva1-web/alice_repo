# Проектирование базы данных

## БД: PostgreSQL

## Назначение

База данных предназначена для информационной системы поиска пропавших домашних животных и помощи приютам.

База данных обеспечивает хранение:

- данных пользователей;
- данных авторизации;
- информации о животных;
- информации о приютах;
- объявлений;
- сообщений пользователей;
- заявок помощи.

---

# Схема `dict`

Содержит справочную информацию.

---

## Таблица `dict.city`

Справочник городов.

### Структура таблицы:

| Поле | Описание |
|---|---|
| city_id | Первичный ключ |
| name | Название города |
| region | Регион |
| country | Страна |

---

## Таблица `dict.animal_status`

Справочник статусов животных.

### Структура таблицы:

| Поле | Описание |
|---|---|
| status_id | Первичный ключ |
| code | Код статуса |
| description | Описание |

### Значения:

| Код | Описание |
|---|---|
| LOST | Потеряно |
| FOUND | Найдено |
| SHELTER | В приюте |
| ADOPTED | Пристроено |
