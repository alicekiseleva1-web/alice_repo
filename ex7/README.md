# Программа для работы с данными фермерских рынков

## Описание

Программа позволяет работать с базой данных фермерских рынков.

Исходные данные загружаются из файла `Export.csv`.

## Возможности

* просмотр списка фермерских рынков с постраничным выводом
* поиск рынков по городу
* поиск рынков по штату
* поиск рынков по ZIP-коду
* поиск рынков в пределах заданного расстояния
* просмотр подробной информации о рынке
* просмотр отзывов и рейтингов
* добавление отзывов с указанием имени и фамилии пользователя
* сортировка рынков по названию, городу, штату и рейтингу
* удаление рынков

## Файлы проекта

* `main.py` — основная программа и консольное меню
* `actions.py` — функции поиска, сортировки, работы с отзывами, расчёта расстояния и удаления рынков
* `data.py` — загрузка данных из CSV-файла
* `test_actions.py` — тесты функций из `actions.py`
* `Export.csv` — файл с данными фермерских рынков

## Запуск

Убедитесь, что все файлы из проекта находятся в одной папке.

Запуск программы:

```text
python main.py
```

## Поддерживаемые команды

* `1` — позволяет просматривать список рынков постранично

пример:

```text
Ваш выбор: 1
Введите страницу: 1
```

После этого можно выбрать номер рынка и посмотреть подробную информацию о нём.

---

* `2` — позволяет найти рынки по городу

пример:

```text
Ваш выбор: 2
Введите город: Chicago
```

---

* `3` — позволяет найти рынки по штату

пример:

```text
Ваш выбор: 3
Введите штат: Illinois
```

---

* `4` — позволяет найти рынок по ZIP-коду

пример:

```text
Ваш выбор: 4
Введите ZIP-код: 60601
```

---

* `5` — позволяет найти рынки в пределах заданного расстояния от определённой точки

Пользователь вводит широту, долготу и максимальное расстояние в милях.

пример:

```text
Ваш выбор: 5
Введите широту: 41.8781
Введите долготу: -87.6298
Введите максимальное расстояние в милях: 30
```

---

* `6` — позволяет сортировать рынки

Доступна сортировка:

* по названию;
* по городу;
* по штату;
* по рейтингу.

При сортировке по рейтингу можно выбрать направление:

```text
1 - От меньшего к большему
2 - От большего к меньшему
```

---

* `7` — позволяет удалить рынок

Пользователь выбирает рынок из списка и подтверждает удаление.

пример:

```text
Введите номер рынка для удаления (0 - назад): 5
Удалить этот рынок? (да/нет): да
```

---

* `0` — завершает работу программы

пример:

```text
Ваш выбор: 0
До свидания!
```

## Работа с отзывами

После выбора конкретного рынка доступны следующие команды:

* `1` — добавить отзыв
* `2` — посмотреть отзывы
* `0` — вернуться назад

При добавлении отзыва необходимо указать:

* имя;
* фамилию;
* рейтинг от 1 до 5;
* текст отзыва.

Текст отзыва может быть пустым.

## Тестирование

Для запуска тестов:

```text
python test_actions.py
```

Тесты проверяют основные функции программы:

* поиск по городу;
* поиск по штату;
* поиск по ZIP-коду;
* постраничный вывод;
* добавление отзывов;
* расчёт среднего рейтинга;
* сортировку;
* расчёт расстояния;
* поиск по расстоянию;
* удаление рынка.
